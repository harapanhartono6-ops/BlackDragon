🚀 BUILD OPTIONS
═══════════════════════════════════════════════════════════════════

OPTION 1: GitHub Actions (Recommended)
  1. Commit changes:
     cd Neko-Kernel
     git add .
     git commit -m "Add BakaSU+SUSFS with Neutron Clang 24"
     git push origin Neko-Baka

  2. GitHub will automatically build the kernel
  3. Download from:
     - Actions artifacts (every commit)
     - Releases (tagged builds)

OPTION 2: Local Build
  1. Download Neutron Clang 24:
     mkdir -p ~/toolchains && cd ~/toolchains
     wget https://github.com/Neutron-Toolchains/clang-build-catalogue/releases/latest/download/neutron-clang-24-aarch64-linux-gnu.tar.zst
     tar -I zstd -xf neutron-clang-24-aarch64-linux-gnu.tar.zst
     mv neutron-clang neutron-clang-24

  2. Build kernel:
     cd /data/user/0/com.airynex.agent/files/home/workspace/Neko-Kernel
     ./build_with_neutron.sh

  3. Flash ZIP from:
     ~/AnyKernel3/Neko-Kernel-BakaSU-*.zip

📱 INSTALLATION GUIDE
═══════════════════════════════════════════════════════════════════

After building:
  1. Boot to recovery (TWRP/OrangeFox)
  2. Flash the kernel ZIP
  3. Wipe cache/dalvik (optional)
  4. Reboot to system
  5. Download and install BakaSU Manager:
     https://github.com/Baka-SU/BakaSU/releases

Testing:
  - Open terminal and run: su
  - Install BakaSU Manager
  - Configure root access for apps
  - Test SUSFS: ksu_susfs (in root shell)
